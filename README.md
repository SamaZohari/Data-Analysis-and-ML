---

## 🔬 Core Focus Areas

### 1. Machine Learning (`ML_Notebooks`)

* **Regression Modeling:** Linear, Polynomial, Ridge ($L_2$), and Lasso ($L_1$) regression for predictive modeling and feature selection.
* **Kernel Methods:** Support Vector Regression (SVR) for non-linear data patterns.
* **Data Preprocessing:** Pipeline creation, handling missing data, standard scaling, and categorical encoding.
* **Dimensionality Reduction:** Principal Component Analysis (PCA) for variance extraction and feature compression.

### 2. Exploratory & Statistical Analysis

* **Olympics Analytics:** Historical athlete demographics, medal distribution, and multi-variable performance trends.
* **Statistical Methods:** End-to-end data cleaning pipelines, distribution checks, and exploratory inference on structured datasets.

## Setup & Execution

1. Clone the repository:
```bash
git clone [https://github.com/SamaZohari/Data-Analysis-and-ML.git](https://github.com/SamaZohari/Data-Analysis-and-ML.git)
cd Data-Analysis-and-ML

```


2. Install dependencies:
```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter

```


3. Start Jupyter:
```bash
jupyter notebook

```
